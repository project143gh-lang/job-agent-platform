# Job Agent Platform

An intelligent job agent platform with web interface. Automate your job search with AI-powered assistance.

## Features

- AI-powered job matching
- Web-based interface
- Job search automation
- Application tracking

## Quick Start

```bash
# Install dependencies
pip install flask

# Run the application
python main.py

# Open in browser
http://localhost:5000
```
